Dokumentasi API Vall CDN

Spesifikasi antarmuka pengunggahan berkas via protokol HTTP standar.

Prinsip kerja edge

Vall CDN memproses pengunggahan berkas biner secara langsung ke kluster edge. Setiap berkas memperoleh pengenal permanen yang dapat diakses langsung oleh peramban atau klien HTTP.

Host dasar layanan

http://localhost:3000/
POST /upload

Struktur payload

Parameter Tipe Deskripsi
file Binary (multipart) Berkas biner target unggah dengan batas volume 2.00 GB

Instruksi pemanggilan

curl -X POST http://localhost:3000/upload \
  -F "file=@/path/to/archive.zip"
